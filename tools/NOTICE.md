# Bundled Windows x64 runtime

These are unmodified local copies of the runtime used to validate this project.

- `sqlcipher.exe` reports SQLCipher 4.5.0 community, SQLite 3.36.0. Source: https://github.com/sqlcipher/sqlcipher/tree/v4.5.0 . Copyright and distribution conditions: `LICENSE.SQLCipher.txt`.
- `libcrypto-3-x64.dll` reports OpenSSL 3.3.0, 9 Apr 2024. Source: https://github.com/openssl/openssl/tree/openssl-3.3.0 . Copyright 1998–2024 The OpenSSL Project Authors. Distributed under Apache License 2.0; see `LICENSE.OpenSSL.txt`.

The original local binary build recipe is unavailable; matching source tags identify the reported versions, not a reproducible-build claim. SHA-256 values in `manifest.json` identify the tested binaries. The runtime checker verifies these values before use during setup.
